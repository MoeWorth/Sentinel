# Sentinel | Open source

Welcome to the official Sentinel repository developed by Moeworth Studios. Here, you’ll find the code intended **EXCLUSIVELY** for local testing from your home.

## Limitations
- You may not copy the code without Moeworth’s explicit permission.
- Compromising the plugin’s security is prohibited.
- This repository is for testing purposes only!

## Build

To compile the plugin, you must meet the following prerequisites:
- Gradle 8.10+
- Java 21

Then, run the *gradle build* command.
